# RideFlow

RideFlow is an intelligent multi-modal journey planner that combines walking, bus, metro, train, auto-rickshaw, and taxi services into a single optimized travel experience.

## Features

* Multi-modal route planning
* Route ranking and recommendations
* Route explanation engine
* Journey booking flow
* Mock payment system
* Digital journey passes
* Live journey tracking simulation

## Tech Stack

### Frontend

* React
* TypeScript
* Tailwind CSS
* Framer Motion

### Backend

* FastAPI
* Python

## Run Frontend

```bash
npm install
npm run dev
```

## Run Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
