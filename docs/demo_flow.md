# Demo Flow

## Demo Scenario

Source: Central Railway Station

Destination: Tech Park

Preference: Balanced

---

## Step 1: Open RideFlow

The user opens the RideFlow application and is presented with the journey search interface.

The search screen contains:

* Source selector
* Destination selector
* Preference selector
* Search button

---

## Step 2: Search for Routes

The user selects:

* Source: Central Railway Station
* Destination: Tech Park
* Preference: Balanced

The user clicks **Search Routes**.

---

## Step 3: Compare Route Options

RideFlow displays multiple journey options.

### Route A (Recommended)

Walk → Bus → Metro → Auto

* Time: 54 min
* Fare: ₹82
* Transfers: 2
* Walking Distance: 650 m

### Route B

Walk → Train → Bus → Walk

* Time: 62 min
* Fare: ₹48
* Transfers: 2
* Walking Distance: 900 m

### Route C

Auto → Metro → Walk

* Time: 45 min
* Fare: ₹120
* Transfers: 1
* Walking Distance: 250 m

The system highlights Route A as the recommended option.

---

## Step 4: View Route Details

The user selects Route A.

RideFlow displays:

* Journey timeline
* Transport modes
* Duration per leg
* Fare per leg
* Transfer points
* Route explanation

---

## Step 5: Route Explanation

RideFlow explains:

"This route is recommended because it provides the best balance between travel time, fare, and walking distance while maintaining high reliability."

---

## Step 6: Book Journey

The user clicks **Book This Journey**.

The system generates:

* Bus Ticket ID
* Metro Ticket ID
* Auto Booking ID

A booking summary page is displayed.

---

## Step 7: Mock Payment

The user proceeds to payment.

Wallet Balance: ₹500

Journey Cost: ₹82

The user clicks **Pay Now**.

Payment status changes to **Success**.

---

## Step 8: Journey Pass Generation

RideFlow generates a unified journey pass containing:

* Journey Pass ID
* Route Summary
* Ticket IDs
* Total Fare
* QR Placeholder

---

## Step 9: Live Journey Tracking

The user starts the journey.

RideFlow displays simulated updates:

* Bus arriving in 4 minutes
* Metro expected on Platform 2
* Auto driver arriving at Gate 3
* ETA updated due to traffic

---

## Step 10: Journey Completion

The user successfully reaches Tech Park.

The system marks the journey as completed.

---

## Final Product Message

RideFlow transforms fragmented urban commuting into one intelligent, explainable, and bookable journey experience.
